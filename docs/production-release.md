## 回復方案
- 若 Pages 正式部署或頁面驗證失敗，使用 Cloudflare Pages Rollback 回復第 2 步記錄的上一個成功正式部署，驗證主網域與購買入口。
- 同時在 GitHub 建立 revert 提交，撤回此次合併及發布提交；不強制推送或改寫歷史，避免後續自動部署再覆蓋回復結果。
- 若只有單一商品入口有問題，先停用該購買按鈕或修正至已驗證入口，保留其他功能及交付資源。
- 301 可能已被瀏覽器或搜尋引擎快取；回復部署不能保證立即撤銷客戶端快取，應維持新目標頁可用。
- noindex 不是付費內容的存取控制；此輪不變更現有授權或交付機制。
